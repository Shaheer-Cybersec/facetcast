# Code of conduct

Facetcast follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, insults, discrimination or sexualised content, in any channel connected to this project.
- Assume good faith, and help newcomers get started.
- Do not post other people's private information.

## Reporting

If someone behaves in a way that breaks these rules, contact the maintainer privately through
[GitHub](https://github.com/Shaheer-Cybersec). Do not open a public issue about it.
Reports are handled confidentially, and the maintainer may remove comments, close issues or block
accounts that break these rules.
